# Obras Jooy - Gestão de Estoque para Obras

Sistema para controle e gerenciamento de estoque, materiais e insumos para canteiros de obras da Jooy.

## Objetivo
Facilitar o acompanhamento de entrada, saída, movimentação e requisição de materiais em diferentes obras e almoxarifados.
